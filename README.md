# ツバキ見積書 🌺

**登録不要・完全無料・データはどこにも送信されない**見積書・納品書ジェネレーターです。
1つの画面で見積書と納品書をワンクリック切替できます。

👉 **今すぐ使う:** https://taku0826.github.io/tsubaki-estimate/

## 特徴

- 🔄 **見積書 ⇄ 納品書をワンクリック切替** — 同じ入力内容から両方の書類が作れます
- ✍️ **リアルタイムプレビュー** — 入力した内容がその場で書面に反映されます
- 🖨️ **印刷 / PDF保存** — ブラウザの印刷機能でそのままきれいなPDFに
- 📋 **見積書の必須項目に対応** — 有効期限・受渡期日・受渡場所・お支払条件
- 💴 **税率別の消費税計算** — 10% / 8%(軽減税率)を品目ごとに設定、軽減税率注記も自動表示
- 🔴 **朱印スタンプ** — 発行者の姓から朱印風のハンコを自動生成
- 🔒 **完全ローカル動作** — サーバーに一切データを送信しません。入力内容はあなたのブラウザの中だけ

## 使い方

1. ページを開く
2. 書類の種類(見積書 / 納品書)を選ぶ
3. 発行者・宛先・品目を入力する
4. 「印刷 / PDF保存」ボタンを押す

それだけです。アカウント登録も、メールアドレスの入力も要りません。

## 仕組み

単一のHTMLファイルだけで動作します。ビルドなし、依存ライブラリなし。
`index.html` をダウンロードしてオフラインで使うこともできます。
